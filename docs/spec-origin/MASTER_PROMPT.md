# PROMPT DE EXECUÇÃO PARA CLAUDE CODE

Você deve construir **DELTABOTS PULSE versão completa de produção**, exatamente segundo os arquivos de especificação deste repositório. NÃO crie MVP. O produto abrange app Android nativo com BLE e persistência offline, Cloudflare API e backend multi-tenant, websockets via Durable Objects, relatórios, console React, mecanismos de automações, módulo de IA com guardrails, MCP/JEV como adaptadores, ponte MQTT opcional operante, driver ESP32-demo, compartilhamento familiar, LGPD, observabilidade, testes, documentação e pipeline de deploy.

**Primeiro ato:** leia `CLAUDE.md`, `README.md`, todos os docs em ordem, contratos e SQL. Gere um mapa de tarefas completo com dependências, critérios de aceite e cobertura por IDs F001–F390 do registro funcional. Não reduza escopo porque não há hardware ou contas/segredos: desenvolva interfaces e fake drivers para testes, bloqueie a conclusão de validação real quando depende de hardware/acesso. Pergunte apenas por permissões/credenciais para deploy e experimentos físicos no ponto em que forem necessárias.

**Demonstre o software, não prometa:** faça commits incrementais com build/test verde; não declare 'implementado' sem artefato executável e testes passando. Inclua provas: logs sem dados pessoais, capturas de testes, resultados CI, medições reais de latência se houver hardware; métricas sintéticas explicitamente rotuladas se não houver. Não force firmware da Mi Band 3, não contorne autenticação de terceiros, não inclua chaves privadas no git. Não copie código AGPLv3 sem decisão jurídica.

**Critério de sucesso:** documentação integrada, console completo com todas as telas, Android completo, APIs reais, RBAC/ABAC, eventos WSS tipados, integridade da telemetria, bridge MQTT segura, automações com simulator/replay, agentes restritos por consentimento, dados exportáveis/deletáveis e gates de hardware & compliance transparentes. Só solicite liberação comercial após a checklist integral em `docs/20-ACCEPTANCE.md` estar satisfeita.

**Mandato obrigatório v1.1:** além dos módulos anteriores, implementar integralmente `Pulse Wearable UI Engine` — F351–F390, Android A65–A76, drivers BLE para atualização de recursos `.res` por variante de Mi Band 3, sem aplicativos intermediários; catálogo/editor/publicador no Console, R2/D1/Workers para artefatos e manifestos assinados, preflight rigoroso, consentimento local, progresso real, logs, validação pós-flash, restauração assistida e suíte HW QA. Ler documentos 34–36 e ADR 0004. Não declarar suporte BLE/rollback/compilação para revisões não comprovadas.
