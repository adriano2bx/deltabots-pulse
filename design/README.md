# DELTABOTS PULSE — VISUAL HANDOFF v1.0

**Conteúdo pronto para designers e Claude Code:** 76 telas Android, 58 telas Console Web, 24 telas conceituais Mi Band 3, fontes SVG/PNG, tokens CSS/TS/Kotlin, ícones SVG/PNG, catálogos JSON, bibliotecas de componentes e galerias HTML offline.

## Abertura rápida
1. Abra `index.html` no navegador; depois `android/gallery.html` e `web/gallery.html`.
2. Consulte `preview/` para pranchas comparativas.
3. Importe SVGs individualmente para Figma, Penpot ou editores vetoriais.
4. Copie tokens e componentes para apps; implemente a interface final em Compose/React usando esses arquivos como referência visual.
5. **Insira antes do release** o logo original no diretório `brand/approved/` (ver README local). O kit não possui master 8C-1, porque os arquivos originais não estavam acessíveis.

## Alcance e honestidade técnica
- 76 Android: **telas de referência visual estáticas**, não código Compose para todas as rotas.
- 58 Web: **telas de referência visual estáticas**, não páginas React completas.
- 24 Wearable: imagens 1-bit 80×128 portrait e previews 6×. **Conceitos, não `.res`/firmware instaláveis**.
- O kit contém código inicial de tokens/estilo e componentes. A implementação funcional e os estados reais pertencem ao PRD v1.1.
- Paleta oficial obtida de `DeltaBots_Website_Build_Spec_v1.0` seção 13, que prevalece sobre as cores provisórias de um mockup anterior do Pulse.
- Os números nas telas são fictícios e intencionalmente rotulados `DEMONSTRAÇÃO`.
